# FreshPantry

A modularized version of the original single-file FreshPantry HTML application.

## Structure

```text
freshpantry/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── assets/
```

## Run

Open `index.html` directly in a browser, or serve the folder with a simple local HTTP server.

No build step is required.

## Notes

- The original hash-based single-page routing is preserved.
- CSS is now in `css/style.css`.
- JavaScript is now in `js/app.js`.
- External Google Fonts and product placeholder images remain external URLs, just as in the original.
